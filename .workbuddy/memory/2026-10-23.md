# 2026-10-23

## 通读项目代码（Arma 3 多实例网页控制器）

- 技术栈：JDK 21 + Spring Boot 3.5.5（spring-boot-starter-jdbc/web/security/validation/websocket/actuator）+ SQLite（xerial 3.46.1.3，WAL）+ JWT(jjwt 0.12.6) + Vue3/Vite/Element Plus/Pinia。
- 结构：聚合 pom（根）+ `backend`（单模块，前端构建产物直接输出到 `backend/src/main/resources/static`，单 jar 提供页面与 API）。前端 12 个视图、后端约 5k 行 Java。
- 后端分层：`web`(11 控制器) → `service`(12) → `repository`(10，JdbcTemplate 手写 SQL，无 JPA/MyBatis) ；`infra/{process,rcon,steam}` 负责游戏进程、BattlEye RCON、SteamCMD 交互会话。
- 关键机制：实例启停走 `job_task` 异步任务（ProcessService 线程池 4）；启动命令由 `StartCommandService` 生成（-config/-cfg 绝对路径、-mod/-serverMod 用模组绝对路径）；SteamCMD 以长驻会话 + 环形内存日志 + seq 增量轮询（`/steamcmd/:sessionId`）。
- 已发现的实现缺口（未修复，仅记录）：`InstanceService.requirePerm` 空实现 → 实例级权限实际未校验；`AssetService.currentUserId()`/`SteamCmdController.userId()` 恒返回 null → 部分审计日志无操作人；`RconService` 注释写 UDP 实为 TCP Socket 且未按 BattlEye 协议封装（magic/CRC/序号缺失）；schema 中 `instance_schedule`/`backup_record`/`game_server_install`/`steam_account`/`user_token` 五张表无任何 Java 引用；Steam 密码以命令行参数传入（进程列表可见）；`docs/index.html` 为早期单页原型。
