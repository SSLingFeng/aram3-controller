# Aram3 Web Server Controller

Веб-панель управления несколькими экземплярами серверов Arma 3 (AppID 233780) на базе **JDK 21 + Spring Boot + Vue 3 + Element Plus + SQLite**.

**Единое приложение**: сборка Vue встраивается в `static` Spring Boot — один jar отдаёт и интерфейс, и API.

## Возможности (текущая версия)

- Авторизация (JWT); при первом запуске в лог бэкенда выводится случайный пароль администратора
- **Управление пользователями**: список / создание / редактирование (отображаемое имя, почта, роли, суперадмин) / сброс пароля / включение-отключение / удаление
- **Системные настройки**: каталог игрового сервера, путь к SteamCMD, каталог модов/Workshop, корневой каталог экземпляров, каталоги журналов/данных (применяются без перезапуска)
- CRUD экземпляров, запуск/остановка, предпросмотр команды запуска (абсолютные пути `server.cfg` / `basic.cfg`, `-ip`, свои аргументы)
- Загрузка карт в формате PBO (автоматический `mapKey`) / удаление; файлы попадают в игровой `mpmissions`
- Моды Workshop: импорт HTML-пресета, обновление (аккаунт Steam + необязательный код), живая консоль SteamCMD
- Статус «локального поиска» модов; «перемещение ключей» в каталог `keys`; управление ключами (источник, удаление, загрузка)
- Настройка загрузки модов для каждого экземпляра (клиент+сервер / только сервер)
- Центр задач
- **Консоль экземпляра (RCON)**: живой список игроков с данными (GUID / IP / пинг / лобби), кик / бан (срок + причина), глобальные объявления и личные сообщения, управление банами (разбан из `bans.txt`, бан по GUID/IP), блокировка / разблокировка сервера, максимум игроков, таймер перезапуска, смена миссии (missions / mission), горячая перезагрузка (loadBans / loadScripts / loadEvents / loadRPT), хвост журнала RPT, консоль сырых RCON-команд
- **Безопасность входа**: `admin` может входить только с сервера (без ограничения числа попыток); остальные аккаунты блокируются после нескольких неудачных попыток (порог настраивается, по умолчанию 3); суперадмин может разблокировать аккаунт и сбросить пароль на 16-символьный случайный (буквы верхнего/нижнего регистра + цифры) в управлении пользователями; блокировка мгновенно отзывает выпущенные токены
- **Многоязычный интерфейс**: 中文 / English / Русский, переключение через иконку глобуса в правом верхнем углу страницы входа и основного интерфейса; выбор сохраняется
- Автоопределение PowerShell (pwsh 7 → powershell 5)
- Автоинициализация SQLite; удобно для обратного прокси Nginx (`VITE_BASE` / `VITE_API_BASE`)

## Сборка и запуск (единое приложение)

### Открытие в IDEA

| Путь открытия | Spring Boot | Конфигурации сборки интерфейса |
|---|---|---|
| Корень репозитория | Агрегирующий `pom.xml` (обновите Maven, чтобы подхватился `backend`) | есть |
| `backend/` | Распознаётся как Spring Boot | есть |

**При открытии из корня**: панель Maven → Reload All Maven Projects.  
Если не распозналось: правый клик по `backend/pom.xml` → Add as Maven Project.

### Конфигурации запуска

| Имя | Назначение |
|---|---|
| **Aram3Application** | Запуск Spring Boot (http://127.0.0.1:8080) |
| **构建前端** | `scripts\build-frontend.cmd` |
| **构建前端(npm)** | `npm run build` |
| **打包前后端** | Сборка интерфейса + упаковка jar через Maven |

Рекомендуемый порядок: **сборка интерфейса** → **Aram3Application**.

### Вручную

```powershell
# Шаг 1: установка зависимостей и сборка интерфейса; результат — backend/src/main/resources/static
cd frontend
npm install
npm run build

# Шаг 2: запуск бэкенда (замените mvn на свой Maven; в IDEA можно просто запустить Aram3Application)
cd ..\backend
mvn spring-boot:run
```

Откройте **http://127.0.0.1:8080**.  
**При первом запуске** в лог бэкенда выводится случайный пароль `admin` (6 символов: буквы верхнего/нижнего регистра + цифра + символ). Сразу смените его после входа.

Опционально режим разработки с раздельным запуском (горячее обновление интерфейса):

```powershell
# Запускает только dev-сервер интерфейса (API указывается через VITE_API_BASE)
cd frontend
npm run dev
```

## Системные настройки

| Параметр | Назначение |
|---|---|
| Каталог игрового сервера | Содержит `arma3server_x64.exe`; карты лежат в `mpmissions\` |
| Путь к SteamCMD | `steamcmd.exe` |
| Каталог модов/Workshop | Общий каталог загрузок Workshop и библиотеки модов |
| Корневой каталог экземпляров | По одному подкаталогу на экземпляр (cfg / profiles) |
| Каталог журналов | Журналы контроллера / задач |
| Каталог данных | SQLite и т. п. (делайте резервную копию в первую очередь) |
| Порог блокировки при ошибках входа | Число неудачных попыток входа до блокировки аккаунтов, кроме `admin` (1–20, по умолчанию 3; см. «Настройки → Безопасность входа») |

## Перед публикацией в GitHub (конфиденциальность)

**Не** публикуйте:

- `data/` (SQLite, `server.cfg`, конфигурация RCON)
- `*.log` (могут содержать аккаунт Steam / SteamID)
- Локальные абсолютные пути, реальные публичные IP, аккаунты Steam, токены, пароли RCON

В продакшене обязательно задайте переменную окружения `ARAM3_JWT_SECRET`.
